AI参与机制设计

四角色系统协同工作，动态策略调整，实现智能化学习辅导

四角色系统

📖
讲解者
用户点击知识点时，提供核心概念讲解，用通俗易懂的方式解释专业知识
❓
提问者
讲解完成后，检验理解程度，提出引导性问题深化理解
✨
纠错者
用户答题错误时，诊断错误类型，提供针对性反馈和修正建议
🎯
规划者
学习进度评估，制定个性化学习路径，推荐下一步学习内容
角色 触发条件 功能 示例
讲解者 用户点击知识点 核心概念讲解 "线性回归通过最小化残差平方和..."
提问者 讲解完成后 检验理解程度 "为什么使用平方而不是绝对值？"
纠错者 用户答题错误 诊断错误类型 "这是计算错误，梯度应该是..."
规划者 学习进度评估 制定学习路径 "建议先复习矩阵运算..."

动态策略调整

// 根据用户状态改变策略
if (errorCount > 3) {
    switchRole('corrector');   // 切换为纠错者
    decreaseDifficulty();      // 降低难度
    provideHint();             // 提供提示
}

if (masteryLevel > 0.8) {
    switchRole('questioner');  // 切换为提问者
    increaseDifficulty();      // 提高难度
    askChallengeQuestion();    // 提出挑战题
}

AI主动介入时机

  1. 学习开始时：讲解者自动介绍核心内容
  2. 答题错误时：纠错者诊断错误类型
  3. 连续正确时：提问者提出进阶问题
  4. 学习停滞时：规划者调整学习路径

错误建模与反馈质量

精细分类错误类型，提供个性化诊断与针对性反馈

错误类型分类

错误类型 识别特征 针对性反馈
计算错误 公式正确但结果错误 "你的思路正确，但计算有误。第3步应该是..."
理解错误 概念应用错误 "这里有个误解：梯度下降是沿着负梯度方向..."
方法错误 选错算法/公式 "这个问题更适合用逻辑回归，因为..."
表达错误 符号/术语错误 "注意区分：θ是参数，x是特征..."

反馈生成逻辑

function generateFeedback(errorType, userAnswer, correctAnswer) {
    switch(errorType) {
        case 'calculation':
            return `计算错误：${userAnswer.step}步骤有误，正确值为${correctAnswer}`;
        case 'understanding':
            return `理解偏差：${userAnswer.misconception}，正确理解是...`;
        case 'method':
            return `方法选择：建议使用${correctAnswer.method}，原因...`;
    }
}
优于统一答案解析，提供个性化诊断。

XGBoost

Extreme Gradient Boosting

📖 什么是 XGBoost？

XGBoost（Extreme Gradient Boosting）是由陈天奇开发的一种高效的梯度提升决策树（GBDT）实现。它是目前机器学习竞赛中最受欢迎的算法之一，以其出色的性能和广泛的适用性而闻名。

XGBoost 通过串行训练多个决策树，每棵树都尝试修正前一棵树的预测误差。它结合了正则化、并行计算、缺失值处理等多种优化技术。

💡 核心直觉：想象一群专家依次给出预测。第一个专家给出初步判断，第二个专家专注于纠正第一个专家的错误，第三个专家纠正前两个专家的错误，依此类推。最终的预测是所有专家意见的加权总和。

📐 数学原理

目标函数
整体目标函数 核心公式
$$\mathcal{L}(\phi) = \sum_{i=1}^n l(y_i, \hat{y}_i) + \sum_{k=1}^K \Omega(f_k)$$
L 由两部分组成：训练损失和正则化项
正则化项 防止过拟合
$$\Omega(f) = \gamma T + \frac{1}{2}\lambda \|w\|^2$$
γ控制树的复杂度（叶子节点数），λ控制叶子权重的L2正则化
泰勒展开近似 二阶优化
$$\mathcal{L}^{(t)} \approx \sum_{i=1}^n \left[ g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \Omega(f_t)$$
使用二阶导数进行更精确的优化，g为一阶导数，h为二阶导数
分裂增益计算
分裂增益 贪心选择
$$Gain = \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} - \gamma$$
GL/GR为左右子树的梯度和，HL/HR为左右子树的二阶导数和

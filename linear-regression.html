线性回归

Linear Regression

📖 什么是线性回归？

线性回归是最基础的机器学习算法之一。它的目标是找到一条最佳直线（或超平面），用来描述因变量和自变量之间的线性关系。

例如：根据房屋面积预测房价、根据学习时间预测考试成绩等。

🎯 核心直觉
想象你在散点图中画一条线，让所有点到这条线的距离总和最小。
💡 生活类比：射箭练习。想要射得越准越好，不断调整瞄准姿势和力度，直到箭头能够尽可能集中地落在靶心周围。

📐 数学原理

📊 基础模型
一元线性回归 基础
$$\hat{y} = w \cdot x + b$$
$\hat{y}$ 为预测值，$w$ 为权重（斜率），$b$ 为偏置（截距）
多元线性回归 扩展
$$\hat{y} = w_0 + w_1x_1 + w_2x_2 + \dots + w_nx_n$$
多个特征的线性组合，$w_0 = b$ 为偏置项
矩阵形式 进阶
$$\hat{y} = X \cdot w$$
$X \in \mathbb{R}^{n \times (d+1)}$ 为特征矩阵，$w \in \mathbb{R}^{d+1}$ 为权重向量
🎯 损失函数
均方误差（MSE） 常用
$$J(w) = \frac{1}{2n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$
最小化预测值与真实值的平方差，1/2 便于求导
均方根误差（RMSE） 评价
$$RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2}$$
衡量预测误差的标准差，与原始数据同量纲
平均绝对误差（MAE） 鲁棒
$$MAE = \frac{1}{n} \sum_{i=1}^{n} |\hat{y}_i - y_i|$$
对异常值不敏感，梯度为常数
⚡ 参数求解
闭式解（一元） 解析
$$w = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}, \quad b = \bar{y} - w\bar{x}$$
直接求解最优参数，无需迭代训练
正规方程（多元） 矩阵
$$w = (X^T X)^{-1} X^T y$$
直接求解多元线性回归的最优解，复杂度 $O(d^3)$
梯度下降 优化
$$w \leftarrow w - \alpha \cdot \nabla J(w)$$ $$\frac{\partial J}{\partial w_j} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i) x_{ij}$$ $$\frac{\partial J}{\partial b} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)$$
$\alpha$ 为学习率，通过迭代更新参数
牛顿法 快速
$$w \leftarrow w - H^{-1} \cdot \nabla J(w)$$
$H$ 为海森矩阵，收敛速度快但计算量大
📈 模型评估
决定系数 R² 核心指标
$$R^2 = 1 - \frac{SS_{err}}{SS_{tot}}$$ $$SS_{err} = \sum (\hat{y}_i - y_i)^2$$ $$SS_{tot} = \sum (y_i - \bar{y})^2$$
衡量模型解释数据方差的能力，范围 $[0,1]$
调整 R² 改进
$$R_{adj}^2 = 1 - \frac{(1-R^2)(n-1)}{n-d-1}$$
考虑特征数量的影响，防止过拟合
F 统计量 检验
$$F = \frac{SS_{reg}/d}{SS_{err}/(n-d-1)}$$
检验回归模型整体显著性
🛡️ 正则化
Ridge 回归（L2） 常用
$$J(w) = \frac{1}{2n} \sum (\hat{y}_i - y_i)^2 + \frac{\lambda}{2} \sum w_j^2$$
$\lambda \geq 0$ 控制正则化强度，防止过拟合
Lasso 回归（L1） 稀疏
$$J(w) = \frac{1}{2n} \sum (\hat{y}_i - y_i)^2 + \lambda \sum |w_j|$$
可实现特征选择，产生稀疏解
Elastic Net 混合
$$J(w) = MSE + \lambda_1 \sum |w_j| + \lambda_2 \sum w_j^2$$
结合 L1 和 L2 正则化的优点
📊 统计推断
系数标准误差 误差分析
$$SE(w_j) = \sqrt{(X^T X)^{-1}_{jj} \cdot \sigma^2}$$
$\sigma^2$ 为残差方差的估计值
t 统计量 检验
$$t_j = \frac{w_j}{SE(w_j)}$$
检验单个系数的显著性
置信区间 推断
$$w_j \pm t_{\alpha/2} \cdot SE(w_j)$$
$t_{\alpha/2}$ 为 t 分布的分位数

⚠️ 局限性

📉
只能拟合线性关系
无法捕捉复杂的非线性模式。
💡 使用多项式回归或神经网络
📍
对异常值敏感
少数异常点会显著影响拟合结果。
💡 使用鲁棒回归或数据预处理
📊
容易过拟合
特征过多时在训练集表现好但测试集表现差。
💡 使用 L1/L2 正则化

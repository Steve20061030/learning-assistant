分治法

Divide and Conquer

📖 什么是分治法？

分治法是一种重要的算法设计范式。其核心思想是将一个复杂的问题分解为两个或更多的相同或相似的子问题，直到子问题简单到可以直接求解，然后将子问题的解合并为原问题的解。

💡 核心直觉：分而治之，古已有之。就像治理一个大国，将其划分为多个省份分别治理。分治法的关键是：分解要均匀，合并要正确。

📐 算法框架

分治法伪代码
function divideAndConquer(problem): if problem 是简单问题: return 求解(problem) # 分：将问题分解为子问题 subProblems = 分解(problem) # 治：递归求解子问题 subSolutions = [] for sub in subProblems: subSolutions.append(divideAndConquer(sub)) # 合：合并子问题的解 return 合并(subSolutions)
经典应用：归并排序、快速排序、大整数乘法

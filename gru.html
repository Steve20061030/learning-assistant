GRU

Gated Recurrent Unit

📖 什么是GRU？

GRU（门控循环单元）是LSTM的简化版本，由Cho等人于2014年提出。它将LSTM的遗忘门和输入门合并为一个更新门，同时合并了细胞状态和隐藏状态，在保持性能的同时减少了参数数量。

GRU在许多任务上表现与LSTM相当，但计算效率更高，因此在资源受限的场景中更受欢迎。

💡 核心直觉：GRU就像一个更简洁的LSTM。它去掉了一些冗余的门，用更少的参数达到类似的效果，就像用更少的零件造出同样强大的机器。

🚪 GRU门控机制

GRU只有两个门：更新门和重置门。更新门控制有多少过去的信息需要保留，重置门控制有多少过去的信息需要忘记。

📐 数学原理

重置门
rₜ = σ(Wᵣ·[hₜ₋₁, xₜ] + bᵣ)
决定如何组合新输入和之前的记忆
更新门
zₜ = σ(W_z·[hₜ₋₁, xₜ] + b_z)
决定有多少过去的信息需要传递到未来
候选隐藏状态
h̃ₜ = tanh(W·[rₜ⊙hₜ₋₁, xₜ] + b)
结合重置门和当前输入计算候选状态
最终隐藏状态
hₜ = (1-zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ
通过更新门平衡过去和现在的信息

⚖️ GRU vs LSTM

特性 GRU LSTM
门数量 2个（更新门、重置门） 3个（遗忘门、输入门、输出门）
参数数量 较少 较多
计算效率 较高 较低
表达能力 略弱 略强
适用场景 序列较短、资源受限 长序列、复杂任务

📜 历史渊源

2014
Cho等人在论文《Learning Phrase Representations using RNN Encoder-Decoder for Statistical Machine Translation》中首次提出GRU。
2015
GRU被广泛应用于神经机器翻译，成为序列建模的主流选择之一。

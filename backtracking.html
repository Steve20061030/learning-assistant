回溯算法

Backtracking

📖 什么是回溯算法？

回溯算法是一种通过搜索所有可能的候选解来找出问题的解的算法。它采用试错的思想，搜索过程中通过剪枝来避免无效搜索。

回溯算法本质上是一种深度优先搜索（DFS），但在搜索过程中会尝试所有可能的选择，当发现当前选择无法得到有效解时，会"回溯"到上一步尝试其他选择。

💡 核心直觉：想象你在走迷宫，尝试每一条路。如果走到死胡同，就退回到上一个岔路口，尝试另一条路。这正是回溯算法的核心思想——"一条路走到黑，不行就退回来重试"。

📐 算法框架

回溯算法伪代码
function backtrack(选择列表, 当前路径): if 满足结束条件: 保存结果 return for 选择 in 选择列表: if 选择有效: 做选择 将选择加入路径 backtrack(剩余选择, 路径) 撤销选择（回溯） 将选择从路径移除
核心是"做选择"和"撤销选择"的对称操作

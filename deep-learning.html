深度学习

Deep Learning

📖 什么是深度学习？

深度学习是机器学习的一个子领域，它使用多层神经网络（深度神经网络）来学习数据的层次化特征表示。深度学习模型通过自动学习从原始数据中提取特征，无需人工设计特征工程。

深度学习在图像识别、语音识别、自然语言处理等领域取得了革命性的突破。

💡 核心直觉
想象一个多层的流水线工厂。原始数据从一端进入，经过多层处理（每层提取不同层次的特征），最终产品从另一端输出。深度学习就像这个自动化工厂，自动学习如何将原始数据转化为有用的预测。

📐 数学原理

🧠 神经网络结构
前向传播 核心
$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$$ $$a^{(l)} = \sigma(z^{(l)})$$
$z^{(l)}$ 为第 $l$ 层的加权输入，$a^{(l)}$ 为激活输出，$\sigma$ 为激活函数
ReLU 激活函数 常用
$$\sigma(x) = \max(0, x)$$
修正线性单元，解决梯度消失问题
⚡ 反向传播
梯度计算 训练
$$\delta^{(L)} = \frac{\partial J}{\partial z^{(L)}}$$ $$\delta^{(l)} = (W^{(l+1)})^T \delta^{(l+1)} \odot \sigma'(z^{(l)})$$
$\delta^{(l)}$ 为第 $l$ 层的误差项，$\odot$ 为逐元素乘积
权重更新 优化
$$W^{(l)} \leftarrow W^{(l)} - \alpha \frac{\partial J}{\partial W^{(l)}}$$ $$\frac{\partial J}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T$$
$\alpha$ 为学习率，通过梯度下降更新权重
📊 损失函数
交叉熵损失 分类
$$J = -\frac{1}{n} \sum_{i=1}^{n} \sum_{k=1}^{K} y_{ik} \log(\hat{y}_{ik})$$
用于多分类任务，$y_{ik}$ 为真实标签，$\hat{y}_{ik}$ 为预测概率

📜 历史渊源

1986
Rumelhart 等人提出反向传播算法。
2006
Hinton 等人提出深度学习概念，使用预训练方法训练深层网络。
2012
AlexNet 在 ImageNet 比赛中大幅超越传统方法，深度学习开始蓬勃发展。
2017
Transformer 架构提出，开启了自然语言处理的新时代。

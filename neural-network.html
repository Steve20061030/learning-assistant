神经网络

Neural Network / Multi-Layer Perceptron

📖 什么是神经网络？

神经网络是一种模仿人脑神经元结构的机器学习模型，由多层神经元组成。通过前向传播和反向传播进行训练，能够学习复杂的非线性关系。

典型应用：图像识别、语音识别、自然语言处理、游戏AI等需要从复杂数据中学习模式的任务。

💡 核心直觉：想象一个由许多微小处理器组成的网络，每个处理器接收输入，进行简单计算，然后将结果传递给下一层。通过大量数据训练，网络学会识别模式。

🏗️ 网络架构

📥
输入层
接收原始数据，如图像像素、文本词向量。每个输入特征对应一个神经元。
⚙️
隐藏层
核心计算层，通过激活函数引入非线性。深层网络能学习更复杂的特征。
📤
输出层
产生最终预测结果。分类任务常用softmax，回归任务直接输出。

📜 发展历史

1943
McCulloch-Pitts神经元：首次提出人工神经元的数学模型。
1958
Rosenblatt感知机：提出感知机学习算法，是第一个可学习的神经网络。
1986
反向传播算法：Rumelhart、Hinton等人提出BP算法，使训练多层网络成为可能。
2006
深度学习元年：Hinton提出深度信念网络，逐层预训练方法开启深度学习时代。
2012
AlexNet突破：ImageNet竞赛中大幅领先，CNN引发计算机视觉革命。

📐 数学原理

单个神经元计算
z = Σ(wᵢ · xᵢ) + b a = σ(z)
其中 w 是权重，b 是偏置，σ 是激活函数
常见激活函数
Sigmoid: σ(z) = 1 / (1 + e^(-z)) ReLU: σ(z) = max(0, z) Tanh: σ(z) = (e^z - e^(-z)) / (e^z + e^(-z)) LeakyReLU: σ(z) = max(0.01z, z)
反向传播（链式法则）
∂L/∂w = ∂L/∂a · ∂a/∂z · ∂z/∂w
通过链式法则从后向前计算梯度，逐步更新权重
梯度下降更新
w ← w - η · ∂L/∂w b ← b - η · ∂L/∂b
η 是学习率，控制更新步长

⚠️ 局限性

需要大量数据
深层网络参数众多，需要大量标注数据才能有效训练
→ 数据增强、迁移学习、预训练模型
训练时间长
反向传播需要多次迭代，GPU加速成为必需
→ Mini-batch、批量正则化、优化器改进
可解释性差
"黑箱"特性使得决策过程难以理解和调试
→ 可解释AI、注意力可视化
容易过拟合
大量参数容易记住训练数据，泛化能力差
→ Dropout、L2正则化、早停

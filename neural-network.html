神经网络

Neural Network / Multi-Layer Perceptron

📖 算法简介

神经网络（Neural Networks）是受人脑启发的机器学习模型——通过层层连接的「人工神经元」，学会从数据中发现规律。

每个神经元接收输入，进行加权求和，通过激活函数产生输出。多层神经元堆叠形成深度网络，能够学习复杂的非线性关系。

🏭 生活类比：工厂流水线
想象一个玩具工厂：原材料（输入数据）进入第一道工序，工人检查形状；第二道工序上色；第三道工序组装……每道工序（每一层）的工人（神经元）只做简单的判断，但经过多道工序后，原材料变成了精美的玩具（准确的预测）。训练就是不断调整每道工序的操作方式（权重），直到产品合格率最高。
💡 逐步理解：
• 神经元 —— 最小单元，接收输入 → 加权求和 → 激活函数 → 输出
• 层 —— 多个神经元组成一层，输入层接收数据，隐藏层提取特征，输出层给出结果
• 前向传播 —— 数据从输入层逐层流向输出层
• 反向传播 —— 根据预测误差，从后往前调整每层的权重

📜 历史渊源

1943
McCulloch-Pitts神经元：首次提出人工神经元的数学模型。
1958
感知机：Rosenblatt发明第一个能从数据中学习的神经网络。
1969
AI寒冬：Minsky证明感知机无法解决XOR问题，神经网络研究陷入低谷。
1986
反向传播算法：Rumelhart等人重新发明反向传播，证明多层网络可以学习任意复杂函数。
2012
深度学习爆发：AlexNet在ImageNet上取得突破性成果，引发AI第三次浪潮。

🏢 工业界地位

神经网络（深度学习）已成为现代人工智能的基石。几乎所有AI应用都依赖神经网络技术，从人脸识别到智能客服，从自动驾驶到推荐系统。

科技巨头的核心技术：Google、Meta、微软、字节跳动等公司的核心AI产品都基于神经网络构建。深度学习已经渗透到计算机视觉、自然语言处理、语音识别等各个领域。

📐 数学原理

前向传播
对于第 l 层的第 j 个神经元： z_j^(l) = sum_i(w_ji^(l) * a_i^(l-1)) + b_j^(l) a_j^(l) = sigma(z_j^(l))
z_j^(l) 是加权输入，w_ji^(l) 是权重，b_j^(l) 是偏置，sigma 是激活函数
激活函数
ReLU: sigma(z) = max(0, z) Sigmoid: sigma(z) = 1 / (1 + e^(-z)) Tanh: sigma(z) = (e^z - e^(-z)) / (e^z + e^(-z))
ReLU最常用，缓解梯度消失；Sigmoid输出在(0,1)；Tanh输出在(-1,1)

Lasso回归

Lasso Regression

📖 什么是Lasso回归？

Lasso回归（Least Absolute Shrinkage and Selection Operator）是一种带有 L1 正则化的线性回归方法。它通过在损失函数中添加权重的绝对值和惩罚项，不仅能防止过拟合，还能实现特征选择。

L1正则化的一个重要特性是可以将一些权重压缩到0，从而实现自动特征选择。

💡 核心直觉
想象你在整理背包，你只能带有限重量的物品。Lasso就像是一个严厉的背包整理师，它会把不重要的物品（特征）直接扔掉（权重变为0），只保留最重要的那些。

📐 数学原理

🔧 损失函数
Lasso 损失函数 核心
$$J(w) = \frac{1}{2n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2 + \lambda \|w\|_1$$
$\lambda \geq 0$ 为正则化参数，控制惩罚强度
L1 范数 惩罚项
$$\|w\|_1 = |w_1| + |w_2| + \dots + |w_d|$$
权重向量的 L1 范数（曼哈顿距离）
⚡ 参数求解
软阈值算子 闭式解
$$w_j = \text{sign}(\hat{w}_j) \max(|\hat{w}_j| - \lambda, 0)$$
$\hat{w}_j$ 为普通最小二乘解，小于 $\lambda$ 的权重被置为0
🔍 特征选择特性
稀疏性 特性
$$\exists \lambda > 0 \implies \|w\|_0 < d$$
存在 $\lambda$ 使得权重向量是稀疏的（只有部分特征有非零权重）
⚖️ L1 vs L2
对比 分析
$$\text{Lasso: } \|w\|_1 \quad (\text{稀疏解})$$ $$\text{Ridge: } \|w\|_2^2 \quad (\text{收缩解})$$
L1产生稀疏解（特征选择），L2产生收缩解（权重衰减）

📜 历史渊源

1996
Robert Tibshirani 首次提出 Lasso 回归。
2000s
Lasso 被广泛应用于基因数据分析等高维特征选择问题。
现代
成为特征选择的标准方法，被 sklearn 等库内置支持。

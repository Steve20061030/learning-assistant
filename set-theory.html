集合论

Set Theory

📖什么是集合论？

集合论是研究集合及其运算的数学分支。集合是由一些确定的、不同的对象组成的整体，这些对象称为集合的元素。集合论是现代数学的基础。

💡 核心直觉
想象一个装满水果的篮子，篮子就是集合，里面的每个水果就是元素。你可以把两个篮子的水果合并（并集），或者找出两个篮子里都有的水果（交集）。

📐集合运算

∪ 并集
并集定义基础
$$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$$
属于A或属于B的所有元素
∩ 交集
交集定义基础
$$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$$
同时属于A和B的所有元素
A 补集
补集定义基础
$$A^c = \{x \mid x \notin A\}$$
不属于A的所有元素

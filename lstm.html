LSTM

Long Short-Term Memory

📖 什么是LSTM？

LSTM（长短期记忆网络）是一种特殊的循环神经网络（RNN），专门设计用于解决传统RNN存在的梯度消失和梯度爆炸问题。它通过引入门控机制，能够有效捕捉长期依赖关系。

LSTM由Hochreiter和Schmidhuber于1997年提出，是深度学习领域最重要的架构之一，广泛应用于自然语言处理、语音识别、时间序列预测等任务。

💡 核心直觉：想象你在读一本书，当你读到后面的章节时，你需要记住前面提到的关键信息。LSTM就像一个有记忆的读者，它能够选择性地记住重要信息，忘记无关细节。

🚪 门控机制

LSTM通过三个门控单元来控制信息的流动：遗忘门、输入门和输出门。这些门决定了哪些信息应该被记住，哪些应该被遗忘。

🗑️
遗忘门 (Forget Gate)
决定从细胞状态中丢弃哪些信息。通过sigmoid层输出0到1之间的值，1表示完全保留，0表示完全遗忘。
➕
输入门 (Input Gate)
决定哪些新信息应该被存储到细胞状态中。由两部分组成：sigmoid层决定更新哪些值，tanh层创建新的候选值。
📤
输出门 (Output Gate)
决定细胞状态的哪一部分会输出到隐藏状态。先通过sigmoid层决定输出部分，再将细胞状态经过tanh处理后乘以sigmoid的输出。

📐 数学原理

遗忘门
fₜ = σ(Wբ·[hₜ₋₁, xₜ] + bբ)
σ是sigmoid函数，Wբ是遗忘门的权重矩阵，bբ是偏置
输入门与候选值
iₜ = σ(Wᵢ·[hₜ₋₁, xₜ] + bᵢ) C̃ₜ = tanh(W_c·[hₜ₋₁, xₜ] + b_c)
iₜ决定哪些值更新，C̃ₜ是新的候选细胞状态值
细胞状态更新
Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ
⊙表示元素级乘法，旧状态选择性遗忘后加上新的候选值
输出门与隐藏状态
oₜ = σ(Wₒ·[hₜ₋₁, xₜ] + bₒ) hₜ = oₜ ⊙ tanh(Cₜ)
隐藏状态是细胞状态的过滤版本

📜 历史渊源

1997
Sepp Hochreiter和Jürgen Schmidhuber首次提出LSTM架构，解决了传统RNN的长期依赖问题。
2000
Felix Gers等人引入了"peephole连接"，允许门直接查看细胞状态，进一步改进了LSTM。
2014
Google使用LSTM实现了神经机器翻译，取得了突破性进展。

Support Vector Machine

📖 什么是SVM？

支持向量机（Support Vector Machine）是一种强大的监督学习算法，通过找到最大间隔超平面来进行分类。它在高维空间中寻找最优决策边界，使得不同类别的样本之间的距离最大化。

💡 核心直觉：想象在一个操场上，有两队不同颜色的球员。你需要画一条线将他们分开，同时要确保这条线离两边球员的距离都尽可能远。SVM就是要找到这条"最公平"的分界线。

📐 数学原理

最优超平面
w·x + b = 0
w是权重向量，b是偏置，这是分类边界
间隔最大化目标
max (2 / ||w||) s.t. yᵢ(w·xᵢ + b) ≥ 1
最大化两类之间的间隔，同时满足分类约束
拉格朗日对偶问题
min (1/2)Σαᵢαⱼyᵢyⱼxᵢ·xⱼ - Σαᵢ s.t. Σαᵢyᵢ = 0, αᵢ ≥ 0
通过对偶变换简化优化问题

排序算法

Sorting Algorithms

📖 什么是排序算法？

排序算法是一种将一组数据按照特定顺序（通常是升序或降序）重新排列的算法。排序是计算机科学中最基础也最重要的操作之一。

常见的排序算法包括冒泡排序、插入排序、选择排序、快速排序、归并排序、堆排序等。

💡 核心直觉
想象你在整理书架上的书，你需要按照字母顺序或大小将它们排列整齐。排序算法就是帮你高效完成这个任务的方法。

📊 算法复杂度

⚡ 比较排序
快速排序 O(n log n)
$$T(n) = 2T(n/2) + O(n)$$
平均情况，最坏情况 $O(n^2)$
归并排序 O(n log n)
$$T(n) = 2T(n/2) + O(n)$$
最坏情况也是 $O(n log n)$，稳定排序
🔄 简单排序
冒泡排序 O(n²)
$$T(n) = \sum_{i=1}^{n-1} (n-i) = O(n^2)$$
相邻元素比较交换
插入排序 O(n²)
$$T(n) = \sum_{i=1}^{n-1} i = O(n^2)$$
对小规模数据效率高

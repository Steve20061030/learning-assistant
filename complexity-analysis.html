复杂度分析

Complexity Analysis

📖什么是复杂度分析？

复杂度分析是评估算法效率的方法，包括时间复杂度和空间复杂度。时间复杂度衡量算法运行时间随输入规模增长的趋势，空间复杂度衡量算法所需存储空间。

💡 核心直觉
想象你要完成一项任务，复杂度分析就是预测任务难度随规模增长的趋势。O(n)表示线性增长，O(n²)表示平方增长，O(log n)表示对数增长。

📐常见复杂度

⏱️ 时间复杂度
O(1) 常数复杂度最优
$$T(n) = O(1)$$
与输入规模无关，如数组访问
O(log n) 对数复杂度优秀
$$T(n) = O(\log n)$$
如二分查找
O(n) 线性复杂度良好
$$T(n) = O(n)$$
如线性查找
O(n log n)较好
$$T(n) = O(n \log n)$$
如快速排序、归并排序
O(n²) 平方复杂度一般
$$T(n) = O(n^2)$$
如冒泡排序、插入排序
